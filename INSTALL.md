# Установка русской локализации It Takes Two

## Требования

Проект предназначен для Linux.

### Проверенная среда

* **OS:** CachyOS x86_64
* **Kernel:** Linux 7.2.4-1-cachyos
* **Shell:** Fish 4.9.3
* **Игра:** It Takes Two
* **Запуск:** Steam + Proton

## Установка

### 1. Скачать архив

Откройте страницу релиза:

**v1.0.0**

Скачайте файл:

```text
GamesVoice_RU_ItTakesTwo.tar.zst
```

### 2. Распаковать архив

Перейдите в каталог, куда был скачан архив.

Например:

```bash
cd ~/Загрузки
```

Распакуйте:

```bash
tar --use-compress-program=unzstd -xvf GamesVoice_RU_ItTakesTwo.tar.zst
```

После распаковки будет создан каталог с файлами локализации.

### 3. Установка

Перед установкой убедитесь, что It Takes Two установлена через Steam.

Далее запустите:

```bash
./install.sh
```

Если Linux сообщает об отсутствии права на выполнение:

```bash
chmod +x install.sh
./install.sh
```

Скрипт установки автоматически выполнит необходимые действия.

## Удаление

Для удаления локализации выполните:

```bash
./uninstall.sh
```

Если скрипт не запускается:

```bash
chmod +x uninstall.sh
./uninstall.sh
```

## Проверка контрольной суммы

Для проверки целостности скачанного архива:

```bash
sha256sum GamesVoice_RU_ItTakesTwo.tar.zst
```

Ожидаемый SHA-256:

```text
b443b795abadab5fe6e921a901fb893a95477b0886ed1220323e3eee2fbe762c
```

Также контрольная сумма находится в:

```text
SHA256SUMS.txt
```

## Важно

Перед установкой рекомендуется закрыть игру.

Если используется Steam/Proton, после установки полностью перезапустите игру.

## Поддерживаемая среда

Локализация разработана и протестирована на:

```text
OS:     CachyOS x86_64
Kernel: Linux 7.2.4-1-cachyos
Shell:  Fish 4.9.3
```

Работа на других Linux-дистрибутивах или версиях Proton возможна, но отдельно не тестировалась.
